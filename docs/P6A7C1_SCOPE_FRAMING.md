# P6A.7C.1 — deterministic scope framing

Framing communicates an already governed boundary. P5 orientation is non-substantive
and binds learning requirements; it does not establish a need for AI prose. This
implementation uses the actual authenticated P6UI.5D specification and imports no
SD formula, Standard Lesson sequence or numerical candidate contract.

`scope-framing/1`, constructed under `bounded-scope-framing/1`, contains exact
source/tier, learning ID/hash, pedagogy ID/hash and approved-pack ID/hash bindings.
The pedagogy identity is its semantic content hash. Source wording and reviewed
canonical meaning are separate objects. Learning intention, approved criteria,
required authored families and every inherited warning are retained.

Each included capability pairs a complete approved criterion with its bounded
action label. Only INTERPRET_SYMBOL and SELECT_SYMBOL have templates. Exclusions
derive from P6A.7C's existing prohibited-content policy: linear solving, number-line
solution sets, compound or quadratic inequalities, regions and unrelated algebra.
Their status is OUTSIDE_SELECTED_OBJECTIVE_SCOPE; no curriculum-wide exclusion is
claimed. Raw PDF glyphs are neither repaired nor interpreted as semantic truth.

The display template is `Learning focus: <governed intention>` followed by
`This lesson is limited to: <approved capability labels>`. Structured evidence
remains authoritative. Provenance distinguishes SOURCE_BOUND_CONTEXT,
REVIEWED_CANONICAL_SEMANTIC, GOVERNED_LEARNING_SPEC,
APPROVED_PEDAGOGICAL_EVIDENCE and DETERMINISTIC_POLICY. Model-authored provenance
and approval/publication claims are forbidden. Per-element capability provenance
and a field-level provenance map cover all semantic fields.

`build_scope_framing` constructs; `validate_scope_framing` independently checks
bindings, projections, scope, warnings, rendering, provenance and identity without
calling the constructor. Shared constants and bounded text rendering are policy,
not a second construction path. Validation re-authenticates upstream evidence.
Recomputed hashes do not make altered content valid.

The existing service accepts the optional `scope_framing` argument in authoring
eligibility evaluation and validation. Missing framing retains the historical
BLOCKED decision. Invalid framing also blocks. A valid artifact satisfies the
retained scope_framing requirement; all other required roles are still checked.
For this target the result is ELIGIBLE_WITH_WARNINGS. This is authoring-contract
readiness, not generated content, live qualification, publication or rendering.

`generic-lesson-authoring-plan/1` contains role dispositions and artifact/validation
hashes only. Scope is DETERMINISTIC_FRAMING; REPRESENTATION and CONCEPT_CHECK are
AI_AUTHORABLE. Optional unimplemented summary remains visible; unsupported roles
are not scheduled. No SL sequence or candidate content is generated.

Tests use real governed evidence with the existing Windows DPAPI review authority,
without writing reviews or credentials. They cover positive framing, independent
validation, two byte-identical replays, invalid and missing artifact gating,
post-validation tampering, authority absence and 23 negative cases whose identities
are recomputed. Prior generic-role and SD/P6 tests remain unchanged.

The current policy is limited to EDX-4MA1-F-2.8-A Foundation. P6A.7D still needs
separately authorized controlled live authoring for the two bounded authored
roles, preserved raw responses and validation evidence. This milestone makes zero
model calls and does not qualify live content or assemble a complete lesson.
